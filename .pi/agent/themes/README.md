# Pi themes

`catppuccin-mocha.json` follows the Mocha theme from
[otahontas/pi-coding-agent-catppuccin](https://github.com/otahontas/pi-coding-agent-catppuccin),
whose package declares the MIT license.

Reference revision: [`9a716a630c911a4d29d9520a8d5f87e3b8867f93`](https://github.com/otahontas/pi-coding-agent-catppuccin/blob/9a716a630c911a4d29d9520a8d5f87e3b8867f93/catppuccin-mocha.json).

The palette, UI color mappings, and HTML export settings match that reference.
Only the schema URL and explicit `appearance: "dark"` metadata differ. Optional
color roles use Pi's built-in fallbacks, just as they do with the reference theme.

The success/error tool backgrounds use the reference's subtle green/red mixes,
following the Catppuccin Delta convention.

Select `catppuccin-mocha` in Pi's `/settings`. After changing the theme manually,
run `/reload` if the active session has not picked it up automatically.
