# Repository instructions

- Always commit completed work directly on `main` and push it to `origin/main`. Do not create pull requests or leave completed work uncommitted.
- Use `fj -H code.moesl.net` (not `gh`) for repository-hosting operations on `code.moesl.net`, including repository creation, issues, pull requests, and releases. Use `git` normally for cloning, fetching, and pushing.
